## OUTREACH STRATEGY

### Phase 1: Initial Contact (Week 1)
1. Send cold email to volunteer coordinators (see template below)
2. Follow up with phone call 3-4 days later if no response
3. Offer free 30-minute consultation call

### Phase 2: Discovery Call (Week 1-2)
1. Understand their biggest time-consuming workflows
2. Identify 1-2 specific problems AI could solve
3. Estimate time savings in hours/week
4. Propose specific 4-6 week pilot project

### Phase 3: Proposal & Agreement (Week 2)
1. Send written proposal (see template below)
2. Define scope, timeline, deliverables
3. Get written approval from director/manager
4. Set kick-off date

### Phase 4: Implementation (Week 3-8)
1. Week 1: Discovery & tool evaluation
2. Week 2-3: Build integration & workflows
3. Week 4-5: Training (staff & volunteers)
4. Week 6-8: Monitor, optimize, document

### Phase 5: Case Study (Week 8-10)
1. Collect metrics (time saved, costs reduced)
2. Get testimonial from director/coordinator
3. Document before/after workflows
4. Create portfolio piece with visuals

## IMPLEMENTATION EXAMPLES BY ORG TYPE

### Food Bank - Volunteer Communication
**Problem:** Coordinator spends 10 hrs/week writing volunteer emails, confirmations, reminders

**Solution:**
- Evaluate: Claude vs GPT-4 vs Gemini for email generation
- Winner: Claude (better instruction following)
- Integration: Google Sheets → Claude API → Gmail
- Templates: Confirmations, reminders, thank-yous, newsletters

**Training:**
- 2-hour workshop: Prompt engineering basics
- Documentation: Step-by-step guide with screenshots
- Support: Weekly check-in for first month

**Results:**
- Time: 10 hrs/week → 2 hrs/week (80% reduction)
- Cost: $18K annual savings (at $35/hr)
- Quality: Volunteers report "more personal" emails
- Adoption: 100% after 2 weeks

---

### Food Bank - Donor Thank-You Letters
**Problem:** Manual thank-you letters, generic and time-consuming

**Solution:**
- Claude API integration with donor database
- Personalized letters referencing donation amount, history
- Automated follow-up sequences

**Results:**
- Time: 5 hrs/week → 30 min/week (90% reduction)
- Quality: Donors report feeling "more valued"
- Retention: 15% increase in repeat donors (6-month follow-up)

---

### Nonprofit - Social Media Content
**Problem:** Need consistent posts but lack time/expertise

**Solution:**
- Weekly activity summary → Claude → 5 social posts + images
- Schedule with Buffer/Hootsuite
- Review queue maintained by staff

**Results:**
- Time: 6 hrs/week → 1 hr/week (83% reduction)
- Engagement: 3x increase in likes/shares
- Reach: 45% increase in followers (3 months)

## RISK MITIGATION

**Potential Objections:**
1. **"We don't have budget"** → "This is free - I'm building my portfolio"
2. **"We're not technical"** → "That's the point - I'll handle the tech, you handle your mission"
3. **"We tried AI and it didn't work"** → "Most people try to use ChatGPT raw. I build custom workflows that actually fit your needs"
4. **"We're too busy"** → "I need about 3 hours of your time total - 1 hour discovery, 2 hours training. The ROI is 10+ hours/week saved"
5. **"We need board approval"** → "No problem - I can present to your board or send a formal proposal"

**Addressing Concerns:**
- Data privacy: "We can use on-premises or privacy-focused tools if needed"
- Reliability: "I build fallbacks and monitoring so you're never dependent on AI being perfect"
- Training: "I provide documentation, videos, and ongoing support"
- Exit strategy: "Everything I build, you own. If you want to stop using it, you can with zero penalty"
